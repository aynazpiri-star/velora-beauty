# آرکا سازه — وب‌سایت معماری، ساخت‌وساز و توسعه املاک

وب‌سایت فارسی و راست‌به‌چپ (RTL) یک شرکت معماری و ساخت‌وساز ایرانی، با React + Vite و
Tailwind CSS. طراحی بر پایه یک مرجع بصری لوکس (زمینه تیره، لبه‌های موجی، لهجه طلایی) شکل
گرفته و کل محتوای آن فارسی است.

## اجرای سریع

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # خروجی تولید
```

## ساختار پروژه

```
src/
  components/   بخش‌های قابل استفاده مجدد (سربرگ، پاورقی، کاروسل‌ها، فرم، ...)
  data/         تمام محتوای قابل ویرایش: پروژه‌ها، خدمات، مقالات، آمار، اطلاعات تماس
  hooks/        هوک‌های مشترک (کاروسل، پرس‌وجوی رسانه‌ای)
  lib/          اعتبارسنجی فرم مشاوره و تبدیل ارقام
  pages/        صفحه اصلی، درباره ما، خدمات، پروژه‌ها، مجله، تماس، مشاوره
```

## ویرایش محتوا

هیچ متن یا تصویری داخل کامپوننت‌ها سخت‌کد نشده است. برای تغییر محتوا:

- پروژه‌ها و تصاویر آن‌ها: `src/data/projects.js`
- تصاویر مشترک: `src/data/images.js`
- خدمات و متن صفحات جزئیات خدمات: `src/data/services.js`
- مقالات مجله: `src/data/posts.js`
- آمار، سال تجربه و مزیت‌های رقابتی: `src/data/stats.js`
- نام برند، اطلاعات تماس، شبکه‌های اجتماعی، لینک‌ها و گزینه‌های فرم: `src/data/site.js`

نمونه‌کارها، آمار و اطلاعات تماس، داده‌های نمایشی برای یک برند فرضی هستند و پیش از
انتشار عمومی باید با محتوای واقعی و تأییدشده شرکت جایگزین شوند.

## فرم مشاوره

فرم به‌صورت پیش‌فرض در حالت نمایشی کار می‌کند: اطلاعات معتبرسنجی می‌شود، در مرورگر
نگهداری می‌شود و پیام «حالت نمایشی» نشان داده می‌شود (هیچ ادعای ارسال واقعی وجود ندارد).
برای اتصال به سرویس واقعی، متغیر محیطی `VITE_CONSULTATION_ENDPOINT` را به نشانی سرویس
دریافت درخواست (POST با بدنه JSON) تنظیم کنید.
