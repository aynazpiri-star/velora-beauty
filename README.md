# Velora

بوتیک آنلاین کفش — فروشگاه فارسی و راست‌به‌چپ با React و Vite، به‌همراه یک API کوچک Express برای ثبت سفارش، نظرات، خبرنامه و پیام‌های تماس.

## اجرا

```bash
docker compose -f docker-compose.base44.yml up -d
```

- فروشگاه: <http://localhost:3000>
- API: <http://localhost:8000/api/health>

## ساختار

| مسیر | توضیح |
| --- | --- |
| `shared/catalog.js` | محصولات، دسته‌بندی‌ها، قیمت‌ها، کدهای تخفیف و محاسبه مبلغ سفارش (مشترک بین کلاینت و سرور) |
| `src/` | رابط کاربری: صفحه اصلی، فروشگاه، دسته‌بندی‌ها، محصول، سبد خرید، تسویه حساب، سفارش، حساب کاربری، درباره ما و تماس |
| `server/index.js` | API سفارش‌ها و فرم‌ها، ذخیره‌سازی در `.data/db.json` |
| `public/images/` | عکس‌های محصولات و دسته‌بندی‌ها |

## امکانات

- سبد خرید و علاقه‌مندی‌ها با ذخیره در مرورگر
- هیرو تعاملی با تغییر رنگ پس‌زمینه بر اساس محصول
- جستجوی زنده، فیلتر دسته‌بندی و مرتب‌سازی
- صفحه محصول با انتخاب رنگ، سایز، تعداد، گالری، مشخصات و نظرات (ثبت نظر واقعی)
- کد تخفیف (`VELORA10`، `VELORA15`)، ارسال رایگان بالای ۸ میلیون تومان
- تسویه حساب سه‌مرحله‌ای با اعتبارسنجی فرم و کد پیگیری سفارش

## نکات

- مبالغ همیشه در سرور از کاتالوگ محاسبه می‌شود؛ قیمت کلاینتی معتبر نیست.
- درگاه پرداخت متصل نیست؛ گزینه‌های «پرداخت در محل» و «کارت به کارت» در نظر گرفته شده‌اند.
- تنظیمات محیط سندباکس در `AGENTS.md` توضیح داده شده است.
